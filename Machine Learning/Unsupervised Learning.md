## Summary

> [!abstract] 
> Is the type of model that doesn't require any labels to perform prediction. Widely use for tasks like [[Clustering]] or Dimension reduction

### Characteristics of unsupervised learning

- No ground truth → hard to assess the result from the model.
- More subjective → no simple goal for the analysis → usually based on rules.
